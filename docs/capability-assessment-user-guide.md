# 业务综合能力评估模块 · 用户操作手册

> 适用对象：康师傅营销团队业务人员
> 配套文档：《能力评估数据字典》（`capability-assessment-data-dictionary.md`）
> 模块版本：v1.0（2026-08）

---

## 1. 模块简介

「业务综合能力评估」以**雷达图（战力图）**形式，从 8 个核心维度综合衡量所别 / 业代 / 全公司的业务能力，并自动生成优势识别、短板定位与改进建议，辅助团队管理与经营决策。

- **评估层级**：所别（区域）或业代（业务人员）两档，支持「全部所别 / 全部业代」整体评估
- **评估周期**：按月份区间（支持 12 个月以上历史数据），可选「无对比 / 环比（上月）/ 同比（去年）」
- **能力等级**：每个维度按得分分为 优势（绿）≥ 75 / 中等（黄）60~74 / 短板（红）< 60
- **综合战力等级**：S ≥ 85 / A 70~84 / B 55~69 / C < 55
- **数据来源**：完全自动——直接复用已上传的客户资料、费用资料与成交数据集，无需手动录入

---

## 2. 快速上手（三步完成一次评估）

1. **进入模块**：点击左侧导航栏「🎯 能力评估」
2. **设置筛选**：选择评估层级 → 评估对象 → 评估月份区间 → 对比方式
3. **确认评估**：点击「确认评估」按钮，自动生成雷达图、得分卡与解读建议

> 若页面提示「暂无业务数据」，说明尚未上传三类数据模板，请先在「数据管理」页上传「数据模板-客户资料 / 费用资料 / 成交数据集」后再返回本模块。

## 3. 界面说明

### 3.1 筛选栏（工具栏）

| 控件 | 说明 | 默认值 |
| --- | --- | --- |
| 评估层级 | 所别 / 业代 | 所别 |
| 评估对象 | 全部所别、具体所别；层级为「业代」时额外显示业代下拉（按所别联动） | 全部所别 |
| 评估月份 | 起始月份 ~ 结束月份，月份随已有数据自动对齐到最新月份 | 最新数据月份 |
| 对比 | 无对比 / 环比（上月）/ 同比（去年） | 无对比 |
| 重置 | 恢复默认筛选并重新评估 | — |
| 确认评估 | 按当前筛选生成评估结果 | — |

操作提示：

- 选择「全部所别」时评估对象为**全公司**；也可选择单个所别评估该区域整体。
- 层级切换为「业代」后，需先选择所别，业代下拉会随之联动；选择「全部业代」即评估该所别全部业代的汇总。
- 月份区间支持跨月（如 2026-01 ~ 2026-06），系统按区间内数据计算。

### 3.2 得分卡片（KPI 卡带）

共 3 张卡片：

1. **综合战力得分**：总分（0~100）＋ 战力等级徽章（S/A/B/C，颜色随等级变化），下方注明评估对象与月份区间。
2. **对比变化**：开启环比/同比后显示分数变化（↑ 绿色 / ↓ 红色）与对比期总分；未开启时显示占位符。
3. **维度能力分布**：优势 / 中等 / 短板维度的数量统计，以及整体趋势提示。

### 3.3 能力雷达图

- **主系列**（品牌蓝实线）：本评估期各维度得分；**对比系列**（灰色虚线）：环比 / 同比对比期得分。
- 维度名称按能力等级着色：绿 = 优势、黄 = 中等、红 = 短板。
- **悬停详情**：鼠标悬停任意维度顶点，弹出该维度的 得分 / 等级 / 原始值 / 权重 / 环比 详情。
- **放大**：点击卡片右上角「放大」按钮，在新弹窗中查看大尺寸雷达图（可进一步聚焦各维度）。

### 3.4 分析与解读面板

| 区块 | 内容 |
| --- | --- |
| 趋势标识 | 右上角显示 ↑ 趋势向好 / ↓ 趋势走弱 / → 趋势平稳（基于对比期） |
| 评估结论 | 一段话概括整体能力水平与核心特征 |
| 核心优势 | 排名前 2 且得分 ≥ 75 的维度，附原因说明（绿色左边框） |
| 关键短板 | 得分最低 2 项且 < 60 的维度，附原因说明与改进建议（红色左边框） |
| 改进建议 | 编号列表给出针对性行动建议 |

### 3.5 维度得分明细表

7 列：维度 / 得分 / 能力等级（含彩色圆点徽章）/ 原始值 / 权重 / 环比 / 同比。

- 得分列按等级着色；环比、同比为正显示绿色、为负显示红色，无数据显示「—」。
- 原始值展示维度真实业务数值（如 ¥7,322,234），得分与原始值可对照理解。

### 3.6 维度设置弹窗

点击页面右上角「维度设置」打开，可调整评估模型：

- **启用开关**：决定该维度是否参与评分与权重合计。
- **权重**：每个维度权重（%），**启用维度权重合计必须为 100%**，否则无法保存（底部会实时显示合计并红字提示）。
- **优势线 / 短板线**：自定义维度等级阈值（默认 75 / 60）。

修改保存后立即生效，后续评估按新配置计算。

### 3.7 导出报告

点击页面右上角「导出报告」按钮，下载 Excel 文件：

- 文件名：`能力评估报告-{对象}-{起始月}~{结束月}.xlsx`
- 内含 3 个工作表：**维度得分**（各维度得分/等级/权重/环比/同比）、**原始指标**（各维度原始业务数值）、**评估结论**（综合得分、等级与改进建议）
- 仅当已确认过一次评估后可用，评估中（loading）不可导出

## 4. 完整使用流程示例

**场景**：评估「华东一」所别 2026 年 6 月的综合能力，并与上月对比。

1. 侧栏进入「🎯 能力评估」
2. 评估层级：所别；评估对象：华东一
3. 评估月份：2026-06 ~ 2026-06；对比：环比（上月）
4. 点击「确认评估」
5. 查看得分卡（总分 + 等级 + 环比变化）→ 雷达图（蓝色实线为本期、灰色虚线为上月）→ 分析与解读 → 维度明细表
6. 点击「导出报告」保存 Excel

## 5. 常见问题（FAQ）

| 问题 | 处理方式 |
| --- | --- |
| 页面显示「暂无业务数据」 | 数据管理页尚未上传三类数据模板（客户资料 / 费用资料 / 成交数据集），请先上传 |
| 页面显示「尚未生成评估结果」 | 属首次进入引导态，选择筛选条件后点击「确认评估」即可 |
| 提示「所别『××』在所选月份内无评估数据」 | 该所别在所选月份区间内没有成交/销额数据，请更换月份区间或评估对象 |
| 选择「全部所别」后总分代表什么 | 代表全公司整体评估（聚合全部所别数据计算） |
| 业代下拉为空 | 该所别暂无业代数据，或需先选择所别再联动加载 |
| 环比/同比显示「无数据」 | 对比期（上月/去年同月）无对应数据，系统自动降级为无对比，不影响主评估结果 |
| 维度设置保存失败提示权重合计须 100% | 调整启用维度或权重，使合计为 100% 后再保存 |
| 业代评估找不到目标人 | 请使用下拉中的完整名称（含编号，如「张裕10437042」），勿手工输入简称 |
| 导出按钮置灰 | 尚未确认评估或正在评估中，先完成一次「确认评估」 |

## 6. 权限说明（RBAC 预留）

- 本阶段权限控制为**预留设计**：系统已内置数据范围表（`capability_user_scope`）与接口过滤逻辑，当后台配置了「用户 × 所别」范围后，用户只能查看权限内所别的评估结果；**未配置时默认全量可见**。
- 维度设置（权重/阈值修改）为管理级配置，请由权限管理员操作。

## 7. 术语表

| 术语 | 含义 |
| --- | --- |
| 维度 | 构成综合能力的单项能力指标（共 8 项，详见数据字典） |
| 原始值 | 维度对应的真实业务数值（如销额、铺货率、临期金额） |
| 得分 | 原始值经标准化后得到的 0~100 分（组内百分位法，反向维度取 100-百分位） |
| 权重 | 维度在综合战力中的占比，合计 100% |
| 环比 / 同比 | 与上月 / 去年同月的数据对比 |
| 战力等级 | 综合总分的 S / A / B / C 等级评定 |
